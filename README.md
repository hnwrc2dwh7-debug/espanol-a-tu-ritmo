# ¡Al grano! · Español a tu ritmo

Una web de práctica del español con más de 400 verbos en español. Es estática: abre `index.html` en un navegador, sin instalación ni cuenta.

## Incluye

- Más de 400 fichas de conjugación en presente, pretérito e imperfecto: verbos regulares, irregulares, con cambio vocálico y pronominales.
- Verbos pronominales como *acostarse*, *sentarse*, *llamarse*, *lavarse*, *vestirse* y *ducharse*.
- Reglas resumidas para los cambios e→ie, i→ie, o→ue, e→i y u→ue.
- Expresiones cotidianas y tres juegos escritos, sin audio.
- Búsqueda por infinitivo, traducción francesa o tipo de verbo.
- Ajustes independientes para el perfil, el tema, el fondo, el tamaño y el espaciado del texto, las traducciones visibles, las etiquetas de las personas, el contraste y las animaciones.
- Guarda el tema, el tamaño de letra y los puntos en el dispositivo con `localStorage`.

El catálogo supera los 400 infinitivos; es amplio y ampliable, aunque no pretende enumerar cada verbo que existe en español.
